# CodTech Machine Learning Internship – Tasks Submission

## 📘 Task 1: Decision Tree
Built a classification model using Scikit-learn on the Iris dataset. Includes model training, testing, and visualization using `plot_tree`.

## 💬 Task 2: Sentiment Analysis
Performed sentiment analysis on IMDb movie reviews using TF-IDF vectorization and Logistic Regression. Includes text preprocessing, vectorization, model training, and classification report.

## 🧠 Task 3: CNN for Image Classification
Used TensorFlow to build a Convolutional Neural Network (CNN) for image classification on the CIFAR-10 dataset. Includes preprocessing, model building, training, and evaluation.

## 🎯 Task 4: Recommendation System
Implemented a collaborative filtering-based recommendation system using Singular Value Decomposition (SVD) from the Surprise library on the MovieLens 100k dataset. Includes training, cross-validation, and rating prediction example.

All tasks are implemented using Python in Jupyter Notebooks and are well-commented for readability.
