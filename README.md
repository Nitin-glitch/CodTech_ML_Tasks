# CodTech_ML_Tasks
Machine Learning Internship Tasks completed for CodTech. This repository includes four core ML projects: Decision Tree Classification, Sentiment Analysis using TF-IDF and Logistic Regression, CNN for Image Classification, and a Recommendation System using Collaborative Filtering.

📘 Task 1: Decision Tree
A classification model built using Scikit-learn on the Iris dataset. Includes training, testing, accuracy evaluation, and visualization with plot_tree.

💬 Task 2: Sentiment Analysis
Analyzed IMDb customer reviews using Natural Language Processing. Used TF-IDF vectorization and Logistic Regression for sentiment classification.

🧠 Task 3: CNN Image Classification
Implemented a CNN using TensorFlow to classify images from the CIFAR-10 dataset. Trained the model and evaluated its performance.

🎯 Task 4: Recommendation System
Built a collaborative filtering recommendation system using SVD with the Surprise library on the MovieLens 100k dataset. Includes evaluation and example prediction.

🧾 All tasks are implemented using Python in Jupyter Notebooks with clean comments and documentation.
